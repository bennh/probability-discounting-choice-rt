# Report source

Copy the official course LaTeX template and `macros_FP` file into this
directory. Keep the required page layout and section headings unchanged.
Generated PDFs and LaTeX build products are ignored by Git; `.tex`, `.bib`,
and macro source files are tracked.

Submission gate:

- use A4, 11 pt, single-column official layout without shrinking content;
- keep the required Introduction, Methods, Results, and Discussion hierarchy;
- limit the Abstract to 250 words and the Introduction-Discussion body to five
  pages;
- place figures, tables, and references after the main body;
- remove all red template guidance;
- state member contributions and the requested assessment type;
- compile the final PDF and verify it visually before submission.
